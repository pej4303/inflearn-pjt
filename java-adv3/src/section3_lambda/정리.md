### 1. 람다(Lambda)

+ Java 8에서 도입된 익명 함수 형태의 표현식
+ 익명 클래스를 간결하게 대체할 수 있는 문법
+ 익명 클래스를 간소화한 도구지만, 내부적으로 인스턴스가 생성됨

**문법**

```text
(매개변수) -> { 본문 }
```

```text
// 매개변수 하나
i -> i + 1

// 매개변수 두 개
(a, b) -> a + b

// 여러 문장
(int a, int b) -> {
    int result = a + b;
    return result;
}
```

### 2. 함수형 인터페이스(Functional Interface)

+ 추상 메서드가 정확히 하나인 인터페이스를 의미
+ `@FunctionalInterface`를 사용하면 컴파일러가 함수형 인터페이스 조건을 검사함
+ `default`, `static` 메서드는 여러 개 정의 가능
+ `Object`의 public 메서드를 오버라이딩한것은 추상 메서드 개수에 포함하지 않음

```java
@FunctionalInterface
interface MyFunction {
    int apply(int value);

    default void print() {
        System.out.println("Hello");
    }
}
```

### 3. 고차 함수(Higher-Order Function)

+ 함수를 매개변수로 전달받거나 함수를 반환하는 함수
+ Java에서는 함수형 인터페이스를 통해 구현할 수 있음
+ 동작 자체를 전달하여 코드의 재사용성과 유연성을 높일 수 있음

```java
public static int calculate(int value, MyFunction operation) {
    return operation.apply(value);
}

// 사용
int result = calculate(10, x -> x * 2);
System.out.println(result); // 20
```

위 예제에서 `calculate()`는 함수형 인터페이스를 매개변수로 받으므로 고차 함수에 해당함
